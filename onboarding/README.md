# Onboarding Automation

Scripts for automating Microsoft 365 user onboarding processes.

## 📌 Purpose
Automates user creation, licence assignment, and group membership to ensure consistent and efficient onboarding.

## 📂 Scripts Included
- New-M365UserOnboarding.ps1

## ⚙️ Key Features
- Bulk user creation from CSV  
- Licence assignment  
- Group membership configuration  
- Logging for audit and troubleshooting  

## 🛠️ Requirements
- Microsoft Graph PowerShell SDK  
- Appropriate admin permissions  

## 🚀 Use Cases
- New employee onboarding  
- Bulk provisioning  
- Standardised user setup
