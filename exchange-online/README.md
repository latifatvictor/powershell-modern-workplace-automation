Scripts focused on mailbox and email-related administration.

Provides visibility into mailbox permissions and email access.

- Get-MailboxPermissionAudit.ps1  

## ⚙️ Key Features
- Mailbox permission auditing  
- Delegated access reporting  

## 🛠️ Requirements
- Exchange Online PowerShell Module  

## 🚀 Use Cases
- Audit readiness  
- Access reviews  
- Compliance checks  

## Get-MailboxPermissionAudit.ps1

Generates an audit report of mailbox delegation and permission assignments in Exchange Online.

### Key outputs
- mailbox display name and SMTP address
- mailbox type
- Full Access assignments
- Send As assignments
- Send on Behalf assignments

### Use case
Supports governance, audit readiness, and mailbox access reviews by improving visibility into delegated mailbox permissions.
