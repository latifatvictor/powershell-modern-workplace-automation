# Access Governance

Scripts for managing and reviewing user access and permissions.

## 📌 Purpose
Supports identity governance and access review processes.

## 📂 Scripts Included
- Invoke-AccessReviewAutomation.ps1  
- Get-InactiveUsersReport.ps1  

## ⚙️ Key Features
- Access review automation  
- Identification of inactive users  
- Governance support  

## 🛠️ Requirements
- Microsoft Graph PowerShell SDK  

## 🚀 Use Cases
- Access reviews  
- Licence optimisation  
- Security governance
