# Offboarding Automation

Scripts for automating Microsoft 365 user offboarding processes.

## 📌 Purpose
Ensures secure and consistent deactivation of user accounts and removal of access.

## 📂 Scripts Included
- Invoke-M365UserOffboarding.ps1

## ⚙️ Key Features
- Account disabling  
- Licence removal  
- Access revocation  
- Logging for audit purposes  

## 🛠️ Requirements
- Microsoft Graph PowerShell SDK  
- Administrative permissions  

## 🚀 Use Cases
- Employee offboarding  
- Security compliance  
- Access cleanup
