# PowerShell Modern Workplace Automation

This repository contains practical PowerShell scripts that support day-to-day administration and operational visibility across the Modern Workplace.

The focus is on **Microsoft 365, Entra ID (Azure AD), and Intune**, with scripts designed to improve:
- Identity and access operations
- Endpoint compliance and device management
- Security and governance checks
- Reporting and operational efficiency

These scripts are written with enterprise environments in mind: clear output, safe defaults, and documentation that explains purpose and usage.
